Asif Ali Portfolio - upload guide (GitHub / Vercel)
===================================================
This version is SELF-CONTAINED: all photos, banners, thumbnails and designs are inside index.html.
You only need:
  1) index.html
  2) the "videos" folder (3 mp4 files)  -> keep it next to index.html
Upload both to the root of your repository (replace the old index.html). No "images" folder is needed.

Contact form email (optional): get a free key at web3forms.com and paste it in CONFIG -> web3formsKey.
